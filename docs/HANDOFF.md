### 画面を手で確かめる時 (確認用の起動)

- 手順: 一時のライブラリと空のモデル置き場で、`KIKIMIMI_LIBRARY_DIR=<一時> KIKIMIMI_MODELS_DIR=<空> build/Kikimimi.app/Contents/MacOS/Kikimimi --selftest-launch 60 --report <ファイル>` を裏で始める → `pgrep -x Kikimimi` で動き出した事と、引数を見る → その後で、アプリを前に出す (同時に送らない) → 最初の絵で、横の一覧が一時の結果である事を見てから、触る。
- 上限は 60 秒 (`LaunchSelfTest.swift`)。1 回の操作のまとまりは、残りの秒数に収める。欄から欄へは Tab キーが確か。
- 設定 (`UserDefaults`) は、ふつうのアプリと同じ物を使う。変えたら戻す。真偽の設定は `-useLedger '<false/>'` の形で渡す。
- 画面の言語は `--ui-language <コード>` で変える (本物の設定は書かない)。画面の文を変えた時は、語の長い言語 (ドイツ語) とタイ語でも、アプリの確認の絵と重さを見る。
- 確認用の結果を消すと、一時の結果のフォルダが macOS のゴミ箱に入る。
- `REAL SETTINGS:` の行: `unchanged` か、`put back N keys the system wrote …` (ふつうの事)。`APP SETTINGS CHANGED …` は、決まりが破れた印 (必ず報告する)。
- でたらめな入力で試す道具は `tools/monkey/README.md` (層 1 = `MonkeyTests`、層 2 = 変な保存ファイルで起こす、層 3 = 変な引数で起こす、層 4 = 開いた後の画面を触る `--selftest-monkey`)。見つけた事は、直すだけで終わらせず、同じ入力で止まる見張りにして残す (README の「見つけた後の手順」)。アプリが落ちた回・道具が止めた回の後は、窓の分け方の鍵が前と違う値で残るので、その鍵だけを前の値に戻す (README の「後片付け」)。(11-29)

### 変えてはいけない物・設計の決め

- 翻訳: 訳す先が日本語の時の決め方・指示文・手本・検査は、前と一字も同じ (試験が見ている)。訳の文を、機械で置き換えない。訳を出さずに訳し直す「重い落ち」は failed・script・long だけ。作らない物: LLM の審査役、訳し戻し、訳語の自動の取り出し、機械の訳のため込み、直しをほかの行へ黙って当てる事。(11-16)
- 測りの決め: chrF は、同じ訳す先の前と後だけを比べる。採る・採らないは 100 行で決める (30 行は 1〜2 点揺れる)。(11-16)
- 「行を直す」: 入口は右クリック。入力は、一覧の外のシート。手で直した区間に当たる監査の直し・提案は取り除く。文を直した区間を含む訳は消す (翻訳は、自動では走らせない)。覚えた組は、1 回で案、2 回で自動。(11-22〜26)
- Return で動くボタン: `.keyboardShortcut(.defaultAction)` が付く `Button` の action は、引数の無い関数を 1 つ呼ぶだけ (`DefaultActionButtonRulesTests`)。(11-26)
- 設定: 書くのは `SettingsWriter` だけ、読むのは `SettingsReader` だけ。確認用の起動の判定は `LaunchMode` だけ。設定の画面が元で、チャットが合わせる。(11-20)
- LLM は、同時に 1 つ。監査・翻訳の途中でも、呼び出しの合間に、チャットが割り込める (`--selftest-llm-queue` が見る)。(11-20)
- チャット: 設定を変える案は `[[set 鍵=値]]` で、当てるのは、利用者が札の「変える」を押した時だけ。リサーチは既定で切。読むのは、利用者が発言に書いた `https` の URL (3 つまで) だけ。リサーチの注意の文 (自己責任) は、変えない。会話は保存しない。(11-20)
- LLM の失敗: 失敗の番号 (-1・-2・-3・-100・-101・-102) は `LLMBatchCheck` が決める。失敗しても、やり直さない・読み直さない (知らせを出して止まる)。監査の答えは「END」で終わる物だけを、書き切ったと見る。(11-28)
- 結果の一覧: 4 つの決まりは `CLAUDE.md`。行は、自分の幅を測らない (`ViewThatFits`・`GeometryReader`・`onGeometryChange` を、行に置かない)。幅で変える物は、一覧が外から受け取る幅から 1 度だけ決めて、値で渡す。(11-27)
- 末尾の追いかけ: macOS 15 以降は、11 行以上がいっぺんに増えたら、10 行ずつ動かす (`TailCatchUp`。待ちは `MainRunLoopTurn`)。短い待ち (タイマー) で間をあけない (CI の Mac では、0.1 秒ほどかかる)。確認の最中だけ、`KIKIMIMI_TAIL_STEPS` (1・0) で切り替えられる。(11-28)
- 画面の文の訳: 日本語の表から鍵を取り出し、足した鍵だけを 11 言語へ訳し、鍵の集合と置き換えの印を確かめる (`docs/L10N.md`)。11 言語の訳は、その言語を話す人の確認が無い。
- モデルを 1 つ足す手順: `models.json` → `/usr/bin/python3 Scripts/generate-model-catalog.py` → 表の訳 → `ModelCatalogDataTests` の数。(11-20)
